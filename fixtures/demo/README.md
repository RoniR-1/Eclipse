# Bundled fictional data

These files contain fictional people, amounts and transactions for local demonstrations. They may be reused and modified for any purpose without restriction. They are not official household statistics. The two-month ledger is a small, internally reconciled example. Tuition samples are illustrative and their median is not a population estimate.

The ten-year Alexia cash-only paths reproduce the numerical assumptions documented in `PHASE_1_AUDIT.md` for the challenge starter example. The JSON files restate those numerical assumptions in an independently authored fictional fixture. The other rows were authored for this repository. Profile P00013 retains the numerical values used in existing loader regression tests, while its identifying fields and ledger are fictional.

`FINANCIAL_TWIN_DATA_ROOT` can point to a compatible challenge data root containing `Data/` and `docs/` for database seeding and synthetic profile projection. The bundled ten-year Alexia comparison remains fixed to these versioned inputs. Use an empty database when changing seed roots.
